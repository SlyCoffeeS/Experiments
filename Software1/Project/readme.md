## How to start

1. You need to have python installed.
2. install VSCode.
3. clone the repository
4. Run the game by clicking "run python file" top right corner in VSCode.

## About
* The goal of this project was to break problems down into smaller parts, develop a program iteratively making small changes at a time, find and fix errors and learn how to use version control

* You can get basic instructions on what to do when selecting instructions from menu selection.
* Game is a dungeon crawler/explorer
* Very short game where you collect item/ defeat slimes/ and escape the dungeon.
